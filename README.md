# Maison Aureum — Template de Loja de Relógios de Luxo

Template front-end pronto para personalizar.

## Como usar
1. Abra `index.html` no navegador.
2. Edite textos, preços e produtos no `script.js`.
3. Edite cores, fontes e espaçamentos no `style.css`.
4. Substitua os blocos "IMAGEM..." por fotografias reais dos relógios.
5. Ligue o botão "Finalizar compra" a Stripe, Shopify, WooCommerce ou outro checkout.

## Estrutura
- `index.html` — estrutura da loja
- `style.css` — design responsivo
- `script.js` — produtos, filtros e carrinho

## Nota
É um template de demonstração: o checkout e o processamento de pagamentos ainda não estão ligados a um serviço real.
